以前のMCP完全解説では、MCPの全体像を学びましたね。今回はいよいよ「自分でMCPサーバーを作る」ハンズオンです。Syntaxと一緒に、PythonでURL要約ツールを作ってClaude Desktopに接続するところまで案内します。

1. MCPガイドの振り返り ― 今日は「自分で作る」

MCP完全解説では、MCPがAIとツールをつなぐ標準プロトコルであること、そしてHost / Client / Server の3層アーキテクチャで動くことを解説しました。

あの記事ではMCPの全体像に焦点を当てましたが、「実際に自分で作ってみたい」という声も多いはず。今回はまさにその実践編です。

今回のゴールはシンプルです。

  • PythonでMCPサーバーを1つ作る
  • 「URLを渡すとWebページのテキストを取得する」ツールを実装する
  • Claude Desktopから呼び出して「このURLを要約して」と頼む

「URLの内容なら、直接Claudeに貼ればよくない？」

そう思った方、鋭いです。確かに、1つのURLを1回だけ要約したいなら、ブラウザでページを開いてテキストをコピーし、Claudeに貼り付ければ済みます。

ではなぜ、わざわざMCPサーバーを作るのか？ 理由は3つあります。

  • 会話の流れを止めない ― 「このURLを要約して」の一言で完結する。3つのURLを比較分析したいとき、いちいちブラウザとClaudeを往復しなくていい
  • URL要約は「練習題材」にすぎない ― 本当に大事なのはClaudeに好きな能力を足せるという事実。社内データベースの検索、Slackへの投稿、IoTデバイスの操作、独自APIとの連携 ― 公開MCPサーバーにない機能を、自分で作れるようになる
  • 仕組みを理解するための最短経路 ― URL取得→テキスト返却は入力と出力が明快で、MCPの動作原理を体感するのに最適。ここで学ぶ @mcp.tool() のパターンは、どんなツールにもそのまま応用できる
Compass

つまり、この記事のゴールは「URL要約ツールを完成させること」ではなく、「MCPサーバーの作り方を身につけること」です。URL要約はそのための題材だと思ってください。

Syntax

MCPサーバーの公式SDKは TypeScript と Python の2つがある。今回は Python の FastMCP フレームワークを使う。デコレータ1つでツールを定義できるので、最短距離でサーバーが立つぞ。

2. FastMCPとは ― Python SDK + 高速フレームワーク

FastMCPは、PythonでMCPサーバーを構築するための高レベルフレームワークです。MCP公式のPython SDKに統合されており、mcp パッケージをインストールするだけで使えます。

FastMCPの特徴は次の通りです。

  • デコレータベースのAPI ― @mcp.tool() を付けるだけで関数がMCPツールになる
  • 型ヒントからスキーマを自動生成 ― 引数の型アノテーションがそのままJSON Schemaに変換される
  • 組み込みのテストサーバー ― mcp dev コマンドで即座にブラウザからテスト可能
  • Claude Desktopへの簡単接続 ― mcp install で設定ファイルを自動生成
Compass

なぜ Python を選んだかというと、データ処理やWebスクレイピングのライブラリが豊富で、MCPツールとの相性がとても良いからです。Python基礎講座を読んでいれば、十分ついてこれますよ。

3. 環境構築 ― 必要なものを揃えよう

必要なものは3つだけです。

  • Python 3.10以上（python --version で確認）
  • pip（Pythonに同梱）
  • Claude Desktop（最終的な接続先）

まずはパッケージをインストールしましょう。

# MCP SDK（FastMCP同梱）+ CLIツール
pip install "mcp[cli]"

# Webページ取得に使うライブラリ
pip install httpx beautifulsoup4
Syntax

mcp[cli] を入れると mcp dev や mcp install といったCLIコマンドが使えるようになる。httpx は非同期対応のHTTPクライアント、beautifulsoup4 はHTMLパーサーだ。

インストール確認をします。

# バージョン確認
python -c "import mcp; print(mcp.__version__)"

# CLIが使えるか確認
mcp --help

エラーなく表示されれば準備完了です。

4. 最初のサーバー ― Hello World ツール

まずは最小限のMCPサーバーを作って、仕組みを体感しましょう。server.py というファイルを作成します。

# server.py
from mcp.server.fastmcp import FastMCP

# サーバーインスタンスを作成
mcp = FastMCP("my-first-server")

@mcp.tool()
def greet(name: str) -> str:
    """指定された名前で挨拶を返します。"""
    return f"こんにちは、{name}さん！MCPの世界へようこそ！"

if __name__ == "__main__":
    mcp.run()

たったこれだけです。ポイントを確認しましょう。

  • FastMCP("my-first-server") ― サーバー名を指定してインスタンスを作成
  • @mcp.tool() ― このデコレータを付けた関数がMCPツールとして公開される
  • 関数のdocstring（"""..."""）がツールの説明文になる ― AIはこれを読んでツールを選択する
  • 型ヒント（name: str）がそのまま入力スキーマになる
Compass

Pythonのdef文と型ヒントの知識がそのまま活きますね。docstringはAIがツールを理解する「説明書」になるので、丁寧に書くのがコツです。

開発サーバーで動作確認

mcp dev コマンドで開発用のインスペクターを起動できます。

mcp dev server.py

ブラウザが自動で開き、MCP Inspector という画面が表示されます。ここで「Tools」タブを開くと greet ツールが見えるはずです。name に自分の名前を入力して実行してみましょう。

Syntax

MCP Inspector はサーバーの動作をブラウザ上でデバッグできるツールだ。ツールの一覧、入力スキーマの確認、実行結果の表示が全部ここでできる。開発中は常にこれを使うと効率がいい。

5. Webページ取得ツールを作る

Hello Worldが動いたら、本題に入ります。URLを受け取って、そのWebページのテキスト内容を返すツールを作りましょう。

server.py を以下のように拡張します。

# server.py
from mcp.server.fastmcp import FastMCP
import httpx
from bs4 import BeautifulSoup

mcp = FastMCP("url-summary-server")

@mcp.tool()
def greet(name: str) -> str:
    """指定された名前で挨拶を返します。"""
    return f"こんにちは、{name}さん！MCPの世界へようこそ！"

@mcp.tool()
async def fetch_webpage(url: str) -> str:
    """指定されたURLのWebページからテキスト内容を取得します。

    Claudeが要約・分析するための生テキストを返します。
    HTMLタグは除去され、本文テキストのみが返されます。

    Args:
        url: 取得したいWebページのURL（https://example.com 形式）
    """
    headers = {
        "User-Agent": "MCP-URL-Summary-Bot/1.0"
    }
    async with httpx.AsyncClient(follow_redirects=True, timeout=30) as client:
        response = await client.get(url, headers=headers)
        response.raise_for_status()

    soup = BeautifulSoup(response.text, "html.parser")

    # 不要な要素を除去
    for tag in soup(["script", "style", "nav", "footer", "header"]):
        tag.decompose()

    text = soup.get_text(separator="\n", strip=True)

    # 長すぎる場合は先頭を切り出す
    if len(text) > 10000:
        text = text[:10000] + "\n\n...(以下省略)"

    return text

if __name__ == "__main__":
    mcp.run()

新しいツール fetch_webpage のポイントを見ていきましょう。

  • async def ― FastMCPは非同期関数をサポート。httpxの非同期クライアントとの相性が良い
  • httpx.AsyncClient ― リダイレクト対応・タイムアウト付きでWebページを取得
  • BeautifulSoup ― HTMLをパースして script や style などの不要タグを除去
  • get_text(separator="\n", strip=True) ― タグを取り除いた純粋なテキストを抽出
  • 10,000文字で切り出し ― MCPのレスポンスが大きすぎるとトークンを圧迫するため
Syntax

docstringの Args: セクションも重要だ。FastMCPはこれを解析してツールの入力説明に使う。AIが「このツールにはURLを渡せばいいんだな」と判断する根拠になる。

動作確認

もう一度 mcp dev で起動して、Inspectorから fetch_webpage ツールを試してみましょう。

mcp dev server.py

Inspectorの「Tools」タブに greet と fetch_webpage の2つが表示されます。fetch_webpage を選び、url に適当なWebサイトのURLを入力して実行してください。HTMLタグが除去されたテキストが返ってくれば成功です。

Compass

Inspector上でテストできるのがFastMCPの良いところ。Claude Desktopに接続する前に、ツール単体で動くことを確認しておくのが安心です。

6. Claude Desktopに接続する

サーバーが完成したら、Claude Desktopから使えるように設定しましょう。

方法1: mcp install を使う（推奨）

FastMCPにはワンコマンドで設定を完了する便利なコマンドがあります。

mcp install server.py

これだけで、Claude Desktopの設定ファイル（claude_desktop_config.json）に自動でエントリが追加されます。

方法2: 手動で設定する

手動で設定する場合は、以下のファイルを編集します。

macOS:

~/Library/Application Support/Claude/claude_desktop_config.json

Windows:

%APPDATA%\Claude\claude_desktop_config.json

ファイルに以下を追記します。

{
  "mcpServers": {
    "url-summary-server": {
      "command": "python",
      "args": ["/absolute/path/to/server.py"]
    }
  }
}
Syntax

args のパスは絶対パスにすること。相対パスだとClaude Desktopがサーバーを見つけられない。macOSなら /Users/yourname/projects/server.py のような形だ。

接続確認

設定後、Claude Desktopを再起動します。チャット入力欄の右下にハンマーアイコン（ツールアイコン）が表示され、クリックすると greet と fetch_webpage がリストに出ていれば接続成功です。

Compass

もしツールが表示されない場合は、Claude Desktopのログ（Settings > Developer > Logs）を確認してみてください。Pythonのパスが違っていたり、パッケージが足りない場合はここにエラーが出ます。

7. 実際に使ってみる ― 「このURLを要約して」

いよいよ実際に使ってみましょう。Claude Desktopで次のように入力します。

このURLの内容を要約してください:
https://example.com/some-article

すると、以下の流れで処理が進みます。

  1. Claudeがメッセージを解析し、「URL要約が必要だ」と判断
  2. 利用可能なMCPツールの中から fetch_webpage を選択
  3. 「ツールを使用してよいですか？」という確認ダイアログが表示される
  4. 承認すると、MCPサーバーがWebページを取得してテキストを返す
  5. Claudeがそのテキストを読み、要約を生成する
Syntax

MCPのポイントは、AIが自分でツールを選ぶところだ。「fetch_webpageを使え」と指示しなくても、Claudeがdocstringを読んで「URLの内容を取得するにはこのツールを使えばいい」と判断する。これがMCPの力だ。

他にもこんな使い方ができます。

  • 「このURLの記事を日本語に翻訳して」
  • 「このURLの技術記事から主要なポイントを箇条書きで整理して」
  • 「このURLとこのURLの内容を比較して」
Compass

自分が作ったサーバーがClaudeの能力を拡張している、と考えるとワクワクしますよね。MCPの面白さは、AIの「手」を自分で作れるところにあります。

8. さらに発展させる

基本のツールが動いたら、さらに機能を追加してみましょう。FastMCPにはツール以外にも、ResourcesやPromptsといった機能があります。

Resourceを追加する

Resourceは、AIが参照できる「データソース」を公開する仕組みです。例えば、よく使うURLのリストをResourceとして提供できます。

@mcp.resource("bookmarks://list")
def get_bookmarks() -> str:
    """よく参照するURLのブックマーク一覧を返します。"""
    bookmarks = [
        "https://docs.python.org/ja/3/",
        "https://modelcontextprotocol.io/",
        "https://httpx.org/",
    ]
    return "\n".join(bookmarks)

複数ツールを追加する

同じサーバーに複数のツールを追加できます。例えば、Webページのメタデータだけを返す軽量版を追加するなら。

@mcp.tool()
async def fetch_page_title(url: str) -> str:
    """指定されたURLのページタイトルを取得します。

    ページ全体を取得せず、タイトルタグのみを返す軽量版です。

    Args:
        url: 取得したいWebページのURL
    """
    async with httpx.AsyncClient(follow_redirects=True, timeout=15) as client:
        response = await client.get(url)
        response.raise_for_status()

    soup = BeautifulSoup(response.text, "html.parser")
    title = soup.title.string if soup.title else "タイトルなし"
    return title

Streamable HTTP への展開

Syntax

今回は stdio トランスポート（標準入出力）で動かしたが、FastMCPは Streamable HTTP トランスポートもサポートしている。これを使えばサーバーをHTTPエンドポイントとして公開でき、リモートからの接続やチームでの共有が可能になる。

# Streamable HTTP で起動する場合
mcp = FastMCP("url-summary-server", transport="streamable-http")

# または起動時に指定
# mcp run server.py --transport streamable-http

Streamable HTTPを使えば、社内ネットワークでMCPサーバーを共有したり、クラウド上にデプロイしてチーム全員が使えるようにすることも可能です。

9. まとめ

この記事では、PythonのFastMCPフレームワークを使ってMCPサーバーを自作する方法をハンズオンで学びました。

  • FastMCPは @mcp.tool() デコレータだけでMCPツールを定義できる
  • Hello World（greetツール）→ 実用ツール（fetch_webpage）とステップアップ
  • mcp dev で開発中にInspectorからテストでき、mcp install でClaude Desktopに接続
  • Resourceや複数ツールの追加、Streamable HTTPへの展開も可能

MCP完全解説で学んだ知識が、今回の実装を通じて「動くもの」になりました。MCPはまだ発展途上のプロトコルですが、だからこそ今のうちに自分でサーバーを書いておくと、エコシステムの成長に合わせてスキルを活かせます。
