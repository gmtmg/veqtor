1. AIが書くコードに「def」がたくさん出てくる

Claude や ChatGPT にプログラムを書いてもらうと、こんなコードがよく返ってきます。

def calculate_total(items):
    total = 0
    for item in items:
        total = total + item
    return total

result = calculate_total([100, 200, 300])
print(result)

def、calculate_total、items、return……。なんとなく動いているけど、これらが何を意味しているのかを今日で完全に理解しましょう。ちなみにこのコードの中に出てくる for は第2回で学んだ繰り返し処理です。

Compass

安心してください。def の仕組みはとてもシンプルです。この記事を読み終わる頃には、AIが書く関数を「なるほど、こういう意味か」と読めるようになりますよ。

2. 関数って何？ ― 名前をつけた処理のまとまり

関数とは、「処理のまとまりに名前をつけたもの」です。

料理で例えると分かりやすいです。

  • 「カレーを作る」= 材料を切る → 炒める → 煮込む → ルーを入れる
  • 「味噌汁を作る」= お湯を沸かす → 具材を入れる → 味噌を溶く

「カレーを作る」と言えば、細かい手順を毎回説明しなくても伝わりますよね。プログラミングの関数も同じです。複数の処理をひとまとめにして名前をつけることで、その名前だけで呼び出せるようになります。

実は、みなさんはすでに関数を使っています。

  • print() → 画面に表示する関数（第1回で学習）
  • len() → 長さを数える関数（第2回で学習）
  • range() → 数列を作る関数（第2回で学習）

これらは Python に最初から用意されている組み込み関数です。今日学ぶのは、自分で関数を作る方法です。

3. 最初のdef ― 関数を作って呼び出す

関数を作るには def キーワードを使います。def は "define"（定義する）の略です。

def say_hello():
    print("こんにちは！")

say_hello()

この3行で「say_hello という名前の関数を作り、呼び出す」ことができます。

  • 1行目: def say_hello(): → 「say_hello という関数を定義するよ」
  • 2行目: print("こんにちは！") → 関数の中身（インデントで示す）
  • 4行目: say_hello() → 関数を呼び出す（実行する）

大事なポイントは2つ。(1) def で定義しただけでは実行されない。say_hello() と呼び出して初めて動く。(2) 一度定義すれば何度でも呼び出せる。これが関数の最大のメリットです。

4. 引数（パラメータ） ― データを渡す

関数をもっと便利にするには、引数（ひきすう）を使います。引数とは、関数に渡すデータのことです。

def greet(name):
    print(f"こんにちは、{name}さん！")

(name) の部分が引数です。関数を呼び出すときに好きな値を渡せます。

引数は複数渡すこともできます。呼び出し側の値が関数のどこに入るか、色で追ってみましょう。

def introduce(name, age):
    print(f"名前: {name}")
    print(f"年齢: {age}歳")
introduce("太郎", 25)
"太郎" が name に入る（1番目 → 1番目）
25 が age に入る（2番目 → 2番目）

変数名が違っても大丈夫

初心者がよく混乱するポイントがあります。呼び出し側の変数名と、関数側の引数名は一致していなくてもいいのです。

user = "花子"
years = 30

introduce(user, years)
変数 user の中身 "花子" が → 関数の name に入る
変数 years の中身 30 が → 関数の age に入る

名前ではなく順番で対応します。user と name は別の名前ですが、どちらも1番目なので中身の "花子" がそのまま name に入ります。

5. 戻り値（return） ― 結果を返す

ここまでの関数は print() で画面に表示するだけでした。でも実際のプログラムでは、関数の計算結果を受け取って次の処理に使いたいことがよくあります。

そこで登場するのが return（リターン）です。色で値の流れを追ってみましょう。

def add(a, b):
    return a + b # 計算結果を返す
result = add(3, 5)
3 が a に入る
5 が b に入る
a + b の結果 8 が return で返され → result に入る

return は「この値を呼び出し元に返す」という意味です。返された値は変数に保存して使えます。ここでも変数名は自由です。result でも answer でも x でも、好きな名前で受け取れます。

コードを試してみよう

print() と return の違いは初心者がつまずきやすいポイントです。

  • print() → 画面に表示するだけ。値は消える。
  • return → 値を呼び出し元に返す。変数に保存したり、次の計算に使える。

print 版の戻り値が None になっているのが分かりましたか？ return がない関数は自動的に None（何もない）を返します。AIが書くコードで return が多いのは、結果を次の処理に使うためです。

6. デフォルト引数 ― 省略できるパラメータ

引数にデフォルト値を設定すると、呼び出すときにその引数を省略できます。

def greet(name, greeting="こんにちは"):
    print(f"{greeting}、{name}さん！")

greeting="こんにちは" がデフォルト引数です。省略すると「こんにちは」が使われます。

8. 演習問題

ここまでの内容を使って、3つの演習問題に挑戦しましょう。

演習問題 問題 1

引数 name を受け取り、こんにちは、○○さん！元気ですか？ と表示する関数 greet を完成させてください。

答えを見る 
def greet(name):
    print(f"こんにちは、{name}さん！元気ですか？")

greet("太郎")
greet("花子")
演習問題 問題 2

価格のリストを受け取り、合計金額を return で返す関数 calc_total を完成させてください。期待される出力: 合計: 600円

答えを見る 
def calc_total(prices):
    total = 0
    for price in prices:
        total = total + price
    return total

prices = [100, 200, 300]
result = calc_total(prices)
print(f"合計: {result}円")
最終チャレンジ 問題 3

身長(cm)と体重(kg)を受け取り、BMIを計算して返す関数 calc_bmi を完成させてください。BMI = 体重 ÷ (身長m)2 です。期待される出力: 身長170cm・体重65kgのBMI: 22.49

答えを見る 
def calc_bmi(height_cm, weight_kg):
    height_m = height_cm / 100
    bmi = weight_kg / (height_m ** 2)
    return round(bmi, 2)

bmi = calc_bmi(170, 65)
print(f"身長170cm・体重65kgのBMI: {bmi}")

まとめ

この記事では、Pythonの関数（def）の基礎を学びました。

  • def 関数名(): で関数を定義する
  • def 関数名(引数): でデータを受け取る
  • return で結果を返す
  • デフォルト引数で省略可能なパラメータを作れる
  • 関数を組み合わせて複雑な処理を整理できる

これで、AIが書くコードに出てくる def の意味がしっかり分かるようになったはずです。第1回（print・変数・if文）、第2回（for文・リスト）、そして今回の def ——ここまで学んだ知識があれば、AIが生成するPythonコードの大部分を読み解けます。
